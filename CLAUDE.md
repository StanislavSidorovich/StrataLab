# StrataLab

Browser SQL workbench (SSMS-lite) on DuckDB-WASM: drop CSV / Excel files, query them with SQL, nothing to install. Part of Quaera (quaera.app); sister apps StrataSQL (model.quaera.app) and StrataFlow (flow.quaera.app). Full spec: `SPEC.md`. Progress, decisions and next steps: `ROADMAP.md`.

- Work stage by stage (SPEC §6); a stage is done only when its acceptance criteria pass. Record choices made on the owner's behalf with ✱ under "Decisions" in ROADMAP.md, and update "Where we are" after each piece of work.
- `src/core/` is pure TypeScript (no React, no DuckDB) and every rule there gets a Vitest test. `src/db/` talks to DuckDB; `src/ui/` is React + Zustand.
- No server: user data never leaves the browser. Dependencies must be permissively licensed; datasets must allow redistribution.
- Check UI changes in the browser (`.claude/launch.json`: `stratalab` = dev on 5180, `stratalab-build` = production preview on 5181). The production build matters: DuckDB's worker and .wasm paths only break there.
- DuckDB-WASM OPFS: we register the database files ourselves (see the decision in ROADMAP.md); don't switch back to `opfs://` paths without checking that the file in OPFS actually grows.
- Local test files go in `data-local/` (git-ignored).
- Datasets: `scripts/build-datasets.py <id> …` rebuilds only those (all when none); builds are byte-for-byte repeatable. AdventureWorks needs a SQL Server once (see the script's header; Docker works), then its JSON cache in `data-local/datasets-src/` is enough.
- DuckDB-WASM loads extensions on first use: Parquet (every dataset load) and ICU (`current_date`, `localtimestamp`, time zones). The site serves its own copies (`npm run extensions` → `public/duckdb-ext/`, run by the deploy; `src/core/extensions.ts`); without them, e.g. in a dev checkout or a cloud session, they come from extensions.duckdb.org, and a network that blocks that host breaks dataset loading. Don't put ICU functions in dataset DDL (`now()` is in the core).
- Python tabs (stage 7) run Pyodide's own builds of pandas, matplotlib and seaborn (+ seaborn's PyPI wheel), served from `public/pyodide/` (git-ignored; `npm run python-packages`, run by the deploy, checks each sha256; `-- --from <pyodide-x.tar.bz2>` takes them from the GitHub release archive when jsDelivr is blocked, as in a cloud session). Without them the worker fetches from jsDelivr. `src/python/lab.py` is the Python side of `lab.table / lab.sql / lab.save`.
- Sample datasets are a public interface: notebooks exported from Python tabs read `https://lab.quaera.app/datasets/<schema>/<file>` (`src/core/ipynb.ts`; file names from `src/data/datasets.json`, e.g. `northwind/Order_Details.parquet`; listed in SPEC §5). Keep those paths and file names stable; a rename breaks notebooks people already downloaded.
- Ecosystem links stay in step with StrataSQL's `src/core/shareLink.ts`: `#ddl=` in (2a), `#sql=…&name=…` out to model.quaera.app (2c); fixtures of what we send live in StrataSQL's `tests/fixtures/stratalab/` (regenerate them with `src/core/modelLink.ts` when the DDL shape changes). Windows are named `stratalab` / `stratasql`.
- Code Apache-2.0. Deployed by GitHub Actions to GitHub Pages on push to main; DNS on Cloudflare.
